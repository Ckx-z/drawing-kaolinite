# Kaolin-Assets · 高岭土机理图绘制软件

> 模块化科研绘图工具：像搭积木一样组合"片层 / 纳米管 / 颗粒 / 分子 / 基底"，
> 生成 SCI 论文与 PPT 汇报用的 2D/3D 机理图。所有素材由 **CIF 晶体学数据 + 参数** 程序化生成，无现成模型库依赖。

## 🚀 快速开始

**方式一（最简单）**：双击 `demo/index.html`。

**方式二（本地服务器）**：

```bash
cd demo
python -m http.server 8613
# 浏览器打开 http://127.0.0.1:8613/
```

操作：左侧素材库点选添加 → 画布点选组件 → 右侧面板调参数
（**埃洛石管的"卷曲进度"滑块 = 片层卷成管的动画**）→ 顶栏 `★存为模块` 积累素材库 → `导出 PNG`（300/600 dpi、可透明底）。

## ✅ 已验证能力

- CIF → 对称展开（26 原子/晶胞，与 Al₄Si₄O₁₈ 化学计量吻合）→ 超胞切片（1–3 层堆叠、矩形/六角轮廓）
- 保弧长卷曲：卷曲进度 0→100% 连续动画；Al-OH 内壁 / Si-O 外壁与真实埃洛石一致；开口端自动断键；锥形管
- CeO₂ 风格簇装颗粒（确定性种子，模块可复现）；H₂O/O₂/CO₂ 等小分子
- 组件独立变换（移动/旋转/缩放 gizmo）、图层面板、显示/隐藏
- 成品模块保存（JSON 参数 + 缩略图）/ 一键复用 / 场景 JSON 存取
- 300 dpi（1890px）/ 600 dpi PNG 导出，透明底
