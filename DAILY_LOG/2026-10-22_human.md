# 2026-10-22 日报（人版）— 软件变好用了：素材能拖着放、画布上直接转

## 这次升级了什么（一分钟版）

以前加素材 = 点卡片 → 组件落在默认位置 → 去右侧面板慢慢调。现在：

1. **素材直接拖进画布**：按住左侧素材卡（甲苯、CeO₂、高岭石……）拖到画布任意位置，半透明预览跟着鼠标走，**松手就落在指针处**。拖到已有组件表面时会"贴"在表面上。按 Esc 随时反悔。
2. **画布顶部多了一排悬浮工具**：移动 / 旋转 / 缩放 / 测量 / 聚焦 / 适配。不用再去参数面板找按钮。快捷键 G（移动）、E（旋转）、S（等比缩放）、F（聚焦选中）、Shift+F（适配全场景）。
3. **分子靠近表面自动贴合回来了**（之前您要求撤销过，这次任务书明确恢复）：拖着分子贴近片层/表面/管时目标会亮起，状态栏提示"松手自动贴合「××」表面"，松手即贴（Alt/Shift 按住 = 自由放置不贴），Ctrl+Z 一步撤销。
4. **测量不用按 Alt 了**：点工具栏「📏 测量」后直接点原子——两点量键长、第三点量键角。
5. **拖到一半按 Esc 能反悔了**：gizmo 拖拽中 Esc = 回到拖动前位置，场景干干净净。

## 顺手修掉的两个隐藏 Bug（重要）

- **测量/氧空位可能选错原子**：多元素晶体（如 CeO₂、水滑石）里，Alt+点击原子时内部把"元素桶内编号"当成了"全局编号"——量键长、放氧空位可能落在**另一个原子**上。已修复并加了回归测试。
- **导出图片可能混入"未确认的吸附候选"**：预览态分子此前可能被导进正式 PNG/TIFF/PDF，且导出一次后画布预览会消失。已修复（五条导出路径全部隔离预览）。

## 电脑环境发现一个坑（需要您知道）

**桌面在 iCloud 同步范围内，软件的依赖文件夹（node_modules）会被 iCloud 悄悄"瘦身"成占位文件**——首次读取要联网下载。这次代码检查工具（eslint）反复卡死就是这个原因（依赖当年经微信传输，还带着隔离标记）。我已经临时修复（清除标记 + 全量下载回来），但**iCloud 空间紧张时可能复发**。长期建议：把整个项目文件夹移出"桌面与文稿"iCloud 同步（或把项目挪到非同步目录）。要挪的话说一声，我来做。
