## 单原子模式增加"单原子层数"（用户 bug 报告 → 功能增强）

### 问题定位
- 用户报告：单原子模式把"所有不同原子替换成一个原子"，无法选择单原子层数。实查：`applyAtomMode`（builders.ts）把组件全部原子 el 统一替换（原子数不变，但不论 layers/walls 设几层，全部层同色同径无法区分层，也无层数选择）。
- 根因：单原子模式无层数维度；Atom 无层标记（多层由 buildSlab 按 k·d001 平移复制，层信息只存在于循环变量）。

### 实现（用户确认语义：选 N → 只显示前 N 层单原子层；默认 = 全部层）
- **内核**：Atom 加可选 `layer?: number`；buildSlab 两分支 k 循环打层标记；羟基 H / 边缘饱和 H 继承所属 O 的层；rollToTube 保留 layer（壁标记随卷曲）；新增 `groupByLayer(atoms)` 纯函数（无标记归第 0 桶）。
- **builders**：`singleModeLayers(total, p)` = single 模式 min(singleLayers??3, layers|walls)，**nc 直接用裁剪值**——显示的 N 层是完整晶体学层（键网/羟基/饱和按 N 层几何自然重算，无需事后删原子重映射 bonds）。
- **schema**：`singleLayersOf = int 1–3 default(3)`（3 = "全部层"哨兵，运行时 clamp）；sheet/tube 加键、颗粒**不加**（无层结构，strictObject 拒绝未知键测试锁定）；DEFAULT_PARAMS 出厂 3。
- **类型**：SheetParams/TubeParams 改 `z.input`（带 default 的新键可选）——测试字面量零改动，运行时 builder `?? 3` 容错。
- **UI**：ParamDef.min/max 放宽为 `number | ((p)=>number)`（向后兼容）；ATOM_MODE_BASE 拆分，片层/管追加 singleLayers 滑块（max 动态 = layers/walls，when atomMode==='single'）；RangeControl 解析函数边界 + 显示值钳制（存量 3 超界时 UI 显示 clamp，store 原值不动）。
