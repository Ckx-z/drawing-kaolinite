## 单原子模式增加"单原子层数"（用户 bug 报告 → 功能增强）

### 问题定位
- 用户报告：单原子模式把"所有不同原子替换成一个原子"，无法选择单原子层数。实查：`applyAtomMode`（builders.ts）把组件全部原子 el 统一替换（原子数不变，但不论 layers/walls 设几层，全部层同色同径无法区分层，也无层数选择）。
- 根因：单原子模式无层数维度；Atom 无层标记（多层由 buildSlab 按 k·d001 平移复制，层信息只存在于循环变量）。

### 实现（用户确认语义：选 N → 只显示前 N 层单原子层；默认 = 全部层）
- **内核**：Atom 加可选 `layer?: number`；buildSlab 两分支 k 循环打层标记；羟基 H / 边缘饱和 H 继承所属 O 的层；rollToTube 保留 layer（壁标记随卷曲）；新增 `groupByLayer(atoms)` 纯函数（无标记归第 0 桶）。
- **builders**：`singleModeLayers(total, p)` = single 模式 min(singleLayers??3, layers|walls)，**nc 直接用裁剪值**——显示的 N 层是完整晶体学层（键网/羟基/饱和按 N 层几何自然重算，无需事后删原子重映射 bonds）。
- **schema**：`singleLayersOf = int 1–3 default(3)`（3 = "全部层"哨兵，运行时 clamp）；sheet/tube 加键、颗粒**不加**（无层结构，strictObject 拒绝未知键测试锁定）；DEFAULT_PARAMS 出厂 3。
- **类型**：SheetParams/TubeParams 改 `z.input`（带 default 的新键可选）——测试字面量零改动，运行时 builder `?? 3` 容错。
- **UI**：ParamDef.min/max 放宽为 `number | ((p)=>number)`（向后兼容）；ATOM_MODE_BASE 拆分，片层/管追加 singleLayers 滑块（max 动态 = layers/walls，when atomMode==='single'）；RangeControl 解析函数边界 + 显示值钳制（存量 3 超界时 UI 显示 clamp，store 原值不动）。

## 新组件类型「密排原子层」（packed_layers）：逐原子堆叠布尔 + 密排层生成

### 需求（用户确认）
"识别单原子属性，允许对每一个单独的原子设置'是否参与堆叠'布尔值；按层数参数生成二维密排原子层并形成三维堆叠"。确认：交互=参数面板网格编辑（每原子一格）；不参与=只保留第一层（上方不生长，台阶/缺陷示意）。

### 实现（新组件类型全链路，标准原子球路径）
- **几何**（builders.buildPackedLayers）：A 位三角网格 `x=(c+(r%2)·0.5)·d, y=r·√3/2·d`；层间滑移 B=(d/2, √3d/6)、C=(d, √3d/3)（3s=A 格矢）；层间距 √(2/3)·d（理想密堆积）；**掩码归属**=上层格点归属水平最近的第一层格点（平局取小索引），'0' 格点的上方原子不生成；原子带 layer 标记；computeBonds 复用。
- **schema**：packedLayerParamsSchema（el/n 2-12/layers 1-8/dist 2-8/stacking AB·ABC/mask ^[01]*$ ≤144 全默认值）；componentSchema+moduleSchema 判别联合；DEFAULT_PARAMS；z.input 类型。
- **接入**：worker computeGeometry case + GeometryKind/Params；RendererService buildData 同步回退 case；TYPE_NAMES「密排原子层」；ModuleFilterType+TYPE_LABELS「密排层」。
- **UI**：paramDefs（el/n/layers/dist/stacking + type:'packedMask'）+ LIB 卡片「⬢ 密排原子层」；ParamPanel **PackedMaskControl**——n×n checkbox 网格（CSS grid 18px 格），toggle 改写 mask 字符串经 updateParams（自动撤销/持久化/缓存失效），全选/清空快捷键 + 参与计数。

## 2026-09-12：修复导入"附加多余氢"（CO 变甲醇）+ 全大写错拆（CO2 变 Co2）

### 检查结论（Explore 全矩阵实测）
- 根因：导入框 SMILES 优先，有机子集原子按价态补隐式氢——"CO"=SMILES 甲醇 CH₃OH（+4H，用户报告）；同类 21 个输入分三类：A 类单元素符号 10 个（O→水、N→氨、C→甲烷…与 Si/Fe/Au 行为不一致）；B 类两元素拼接 11 个（CO/NO/CN/CS/SO/BO/CF/SN/NS/PO/CI→各氢化物）；C 类 4 个（CCO 乙醇等真 SMILES，非 bug）。
