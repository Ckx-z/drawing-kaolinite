# 日报 2026-09-09（人版）

## 你要的四个功能/修复全部完成 ✅

1. **方向键平移画板**：按住键盘 ↑↓←→ 画布向对应方向平滑移动（约 360 像素/秒，可斜向组合），松开即停，切换窗口也不会"卡键"。**光标在输入框里打字时，方向键只移动光标，不会动画板**。

2. **导入框支持化学式（大小写随便输）**：现在同一个框里，先按 SMILES 解析（输入 CCO 仍是乙醇），不认识就自动当化学式处理——**si、SI、Si 都能出硅原子**；fe2o3 → Fe₂O₃ 五原子团、nacl → NaCl、H2O → 水分子，全部自动生成 3D 模型（原子按真实半径紧密堆叠并自动连键）。元素库补齐了氯、溴、氟、铁、铜等 17 个常用元素。

3. **单原子模式开关**：高岭土片层 / 埃洛石管 / 纳米颗粒 三类素材的参数面板新增「单原子模式」——开启后整个结构用**同一种原子球堆叠**（元素可选 Si/Al/O/Fe/Ce/Ti/C），关闭恢复完整化学结构。每个实例独立开关、切换即刻刷新画面、随场景文件一起保存。

4. **导出终于能用了 + 自己选保存位置**：之前打包版软件里点"导出"其实完全没反应（系统浏览器内核不支持那种下载方式）。现在点击任何导出（PNG/TIFF/PDF/SVG/GIF/场景文件）都会**先弹出系统保存对话框**，自己选文件夹和文件名；分层 PNG 选一个文件夹自动批量写入。**点取消则什么都不发生、不报错**。浏览器版同样升级（能用"另存为"对话框的浏览器会弹框，其他保持原下载方式）。
