## 追加：T-5.1 TIFF 导出 —— P1 收官（会话 2026-09-06-09，0.5d）

### 关键实现取舍
方案原文拟用 UTIF.encodeImage，但**其不写入 XResolution/YResolution 物理分辨率标签**（验收硬要求"正确物理尺寸与 300dpi 元数据"），故改为**内置无压缩 RGBA TIFF 编码器**：~100 行、零依赖、Node 可单测，13 标签完整控制：
- 282/283 XResolution/YResolution = dpi（RATIONAL）+ 296 ResolutionUnit=inch → PS/GIMP 打开即 16cm 物理宽；
- 277 SamplesPerPixel=4 + 338 ExtraSamples=2（unassociated alpha）→ 透明底；
- 259 Compression=1：16cm@300dpi ≈ 11MB，投稿无碍。

### 工程结构
- `resolveExportSize` 纯函数：px=cm×dpi/2.54 + maxTextureSize 钳制（降级返回 effectiveDpi；exportPNG 一并复用，获得同款保护）；
- RendererService：beginOffscreen/endOffscreen 抽取（PNG/TIFF 共用离屏会话）；exportTIFF 经 2D 画布 drawImage 取像素（自动处理 WebGL 上下翻转）；
- TopBar「导出 TIFF」：降级时 flash 提示有效 dpi。

### 验收（标准逐条核对）
- ✅ 浏览器实测（真实示例场景）：16cm@300dpi → **1890×1591px，macOS sips 读出 dpiWidth/dpiHeight=300.000/300.000、format=tiff**（Photoshop/GIMP 将显示相同物理尺寸）；
- ✅ 600dpi 超限：resolveExportSize 按比例降级、保持宽高比、effectiveDpi 同步（单测覆盖；UI 提示路径 flash）；
- ✅ 编码器二进制逐字段解析回读（II 头/IFD 13 标签/Rational 回读/像素 StripOffsets 回读/末行 alpha）5 条。

## 追加：T-2.8 SMILES 分子导入 v1.0（会话 2026-09-06-16，双会话协作约 1.5d）

### 实现偏差说明（对 D08 实现细节，决策本质"SMILES 先行"不变）
不引入 RDKit WASM：~10MB 依赖 + 懒加载/locateFile 复杂度 + minimal-lib 3D 构象 API 可用性存疑。改为**内置 smiles.ts**（零依赖、离线、确定性、Node 可单测）：解析器 + 规则式 3D 构象（示意级精度）。接口已抽象（smilesTo3D(graph)），若后续精度不足可无感换装 RDKit WASM 增强。

### 功能结构（两个并行会话互补合并——git 工作区协作，无冲突）
- **core**（本会话）：解析器（有机子集/方括号/芳香/环闭合/分支/断键）+ 构象生成（环系平面正多边形 → 稠环共面延展 ± 转向择优 → 模板 BFS 生长 → 槽位碰撞规避 → 弛豫+键长校正）；schema molecule.smiles；渲染双路（Worker computeGeometry + 主线程 buildData 回退）。
- **UI/Worker**（并行会话）：LibraryPanel SMILES 输入框+导入按钮（本地预校验）+ Worker computeGeometry smiles 分支。

### 调试过程（关键坑）
1. 解析器漏单字符有机子集分支（O/C/N 无法识别）；
2. fullAdj 在加氢展开前分配 → 氢原子索引越界（"全原子表先建全再建邻接"原则）；
3. 芳香小写元素未规范化 → 渲染配色查不到（统一 toUpperCase）；
4. placeNeighbor 绕**新键方向**旋转的二面角候选全部重合（offset 与轴共线）→ 碰撞规避失效；正确轴=父原子参考键方向；且 nextDirection 升级为**槽位评分**（全部空闲模板槽位的候选锚点取碰撞最小）；
5. 断键分子孤立原子未被 BFS 覆盖 → 连通分量标记，无已放置原子的分量才起根（错位 9Å 摆放+全局弛豫分开）；
