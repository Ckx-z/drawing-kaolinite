- App.tsx：keydown/keyup 维护方向键集合 + rAF 帧循环（6px/帧 ≈ 360px/s，按住连续、松开停止、斜向速度合成）；window blur 清空防"卡键"；输入框聚焦守卫复用现有 input/select/textarea 判断（实测 focus 输入框时位移 0.000）。

### 2. 化学式导入（大小写不敏感）
- 新模块 `src/core/molecules/formula.ts`：parseFormula（严格模式保留大小写语义 Co=钴；**全大写/全小写=大小写信息缺失→宽松归一**，si/SI/sI→Si，双字母元素优先贪心拆分 nacl→NaCl）+ buildFormulaCluster（贪心表面吸附生长紧密团簇：**紧凑为主项、穿透强惩罚、微偏好留缝**——首版"间隙最大化"主项会把原子推离表面脱离键程，已修）+ 近距共价半径自动连键（H-H 不连）。
- 输入链路（LibraryPanel）：先 SMILES（CCO=乙醇不回归）失败自动转化学式；规范化串存 `params.formula` 随场景持久化；computeGeometry 与 RendererService.buildData（同步回退）双路接入。
- 元素表扩 17 个常用元素（F/Cl/Br/I/Li/B/V/Cr/Mn/Co/Ni/Cu/Zr/Mo/Ag/Sn/Ba，Cordero 半径+柔和配色）——Cl 是 NaCl 场景必需。
- 已知取舍：全大写"CO"归一为 Co（钴）；一氧化碳走 SMILES 链路（"CO"是合法 SMILES）。

### 3. 单原子模式（片层/管/颗粒）
- schema：sheet/tube/particle params 加 `atomMode: 'full'|'single'`（default full，旧场景自动兼容）+ `singleEl`（默认 Si/Si/Ce）；随场景 JSON 持久化（每实例独立）。
- builders：`applyAtomMode` 统一元素标识（几何骨架与键网不变，渲染层按 el 取半径/颜色→视觉即单一原子堆叠）。
- UI：ParamDef 新增 `toggle` 类型（字符串枚举↔勾选态映射）与 `when` 条件显隐（元素选择仅开启时显示；molecule 的 kind 选择器在 smiles/formula 分子下隐藏防误导）。
- 实测：片层 Al/H/O/Si → 勾选后全部 Si（原子数 3332 不变）。

### 4. 导出修复 + 原生保存对话框
- **根因**：打包版 WKWebView 里 `<a download>` 点击无效——所有导出（PNG/TIFF/PDF/SVG/分层/GIF/场景 JSON）在桌面端全部落空。
- 方案：`src/ui/saveFile.ts` 统一入口——桌面端 `@tauri-apps/plugin-dialog` save() 原生对话框（defaultPath + 扩展名过滤器）→ `invoke('save_file')` Rust 写盘；浏览器端 showSaveFilePicker（Chromium）→ 不支持退回 a[download]。取消=静默 return false 不报错。
- Rust（main.rs）：`save_file(path, filename?, data)` 命令——path 为目录时自动拼 filename（分层 PNG 选一次目录批量写）；Cargo + tauri-plugin-dialog；capabilities/default.json（core:default + dialog:default）。
- TopBar 全部 7 个导出入口接入（分层 PNG 走 saveBlobs 目录模式）。
- 浏览器实测：点击导出 PNG → 原生保存框弹出（pickerSupported=true，Promise 挂起等待用户）→ Escape 取消 → 零报错零 toast ✓。
