## 2. 总体架构

```
┌────────────────────────────────────────────────────────────────────┐
│ UI 层（React）                                                      │
│  素材库面板 │ 参数面板 │ 图层面板 │ 画布(Viewport) │ 顶部工具栏/导出     │
├────────────────────────────────────────────────────────────────────┤
│ 应用层                                                              │
│  场景图管理(Document/Component)  命令栈(撤销/重做)                    │
│  模块库管理(入库/检索/缩略图)     工程/场景序列化(JSON)                │
├────────────────────────────────────────────────────────────────────┤
│ 几何内核（纯 TypeScript，零 UI 依赖，可进 Worker / Node 批处理）       │
│  CIF解析 → 对称展开 → 超胞切片 → 卷曲成管 → 键连判定 → 羟基/边缘饱和    │
│  颗粒生成(斐波那契簇装)  分子库  基底  ……（全部是 params→atoms 纯函数） │
├────────────────────────────────────────────────────────────────────┤
│ 渲染层                                                              │
│  Three.js 实例化渲染(InstancedMesh)  PBR材质  环境光/PMREM            │
│  双轨渲染：渲染档(PBR位图) ⇆ 线稿档(扁平色块/描边，可矢量化)            │
├────────────────────────────────────────────────────────────────────┤
│ 导出层                                                              │
│  高分辨率位图(300/600dpi, 透明底)  TIFF/PDF 编码  分组SVG → PPT/EMF   │
└────────────────────────────────────────────────────────────────────┘
数据流：参数 → 几何(纯函数) → 原子+键 → 实例化网格 → 场景图 → 渲染/导出
```

**关键架构决策**

1. **几何内核与渲染解耦**。内核输入参数、输出原子与键的纯数据，不知道 Three.js 存在。好处：① 可以放进 Web Worker，UI 不卡；② 可以在 Node 端离线"烘焙"常用尺寸素材进模块库；③ 算法可以独立单元测试（本项目已用 Node 跑通全链路自测，见 `demo/core/test.js`）。
2. **非破坏式数据模型**（§4）。文档里只有参数，网格永远是缓存。这是"二次编辑"承诺的技术保障。
3. **示意正交化**。三斜晶胞 β=104.9°，直接投影层片是斜的、卷曲轴也歪。机理图不是衍射模拟：保留晶轴**长度**、消去晶轴间**夹角**（键长畸变 < 5%，视觉不可辨），换来了"片层水平、z 即层法向、卷曲干净"的全部便利。这是示意图软件的行业标准取舍。

## 4. 数据模型（决定"二次编辑"能力的一节）

### 4.1 场景文档 `kaolin-scene/v1`

```jsonc
{
  "format": "kaolin-scene/v1",
  "saved": "2026-09-04T15:00:00Z",
  "components": [
    {
      "id": "c1",
      "name": "埃洛石管（双层壁）",
      "type": "halloysite_tube",          // 指向几何内核的 Builder
      "params": {                          // ← 存参数，不存网格！
        "innerR": 14, "length": 100, "walls": 2,
        "d001": 10, "progress": 1.0, "taperDeg": 5,
        "style": "空间填充"
      },
      "transform": {                       // 位置/旋转/缩放独立于几何
        "position": [10, -6, 0],
        "rotation": [0, 0, 90],
        "scale": 1
      },
      "visible": true,
      "locked": false                      // 锁定后防误改（路线图）
    }
  ]
}
```

### 4.2 成品模块（模块库条目）

```jsonc
{
  "id": "m1725…",
  "name": "三层片层+CeO2颗粒",
  "type": "kaolinite_sheet",             // 单组件模块；组合模块= components[]
  "params": { "Lx": 70, "Ly": 60, "layers": 3, "shape": "六角", … },
  "transform": { … },
  "thumb": "data:image/jpeg;base64,…"    // 入库时自动快照，素材库可视化浏览
}
```

- **单组件模块**与**组合模块**（一次存整个场景或选区）共用同一 schema，组合模块多一个 `components[]`。
- 存储分层：浏览器期 → IndexedDB（大）+ localStorage（缩略图索引）；桌面端 → 工程目录下的 `.kaolin/` 文件夹，**随课题组网盘同步**，新学生拷走文件夹即继承全部家底。
- 因为只存参数：换电脑、升级软件版本、半年后打开，模块仍能以当前最新渲染质量重新生成——这是"渐进式积累 8–10 个模块"战略的数据基础。

### 4.3 二次编辑的三条兑现路径

| 路径 | 操作 | 适用 |
|---|---|---|
| 软件内 | 模块拖入 → 图层面板解锁 → 拖图层/改参数 | 日常科研绘图 |
| PPT-矢量 | 导出**分组 SVG**（每个组件 = 一个 `<g id="图层名">`）→ PPT 插入 → 右键"转换为形状"→ 取消组合 → 每个结构可改色/移动 | 汇报 PPT 深度改造 |
| PPT-位图 | 导出**分层透明 PNG**（每图层一张）→ PPT 内叠放，可单独移动缩放 | 保留渲染质感 + 适度编辑 |
| Office 原生 | 桌面端调 Inkscape CLI：`inkscape in.svg --export-type=emf` → EMF 插入 Office | 老版本 Office 兼容 |

## 5. 核心算法与代码实现

> 以下代码全部来自已交付并测试通过的 `demo/core/`（生产版只需原样转 TypeScript + 补类型）。

### 5.1 从 CIF 到片层的完整管线

高岭石是 TO 型 1:1 层状硅酸盐（硅氧四面体片 T + 铝氧八面体片 O），晶胞参数 a≈5.16、b≈8.94、c≈7.40 Å。管线：

```
CIF 文本 → parseCIF → expandSymmetry(对称操作展开)
        → buildSlab(na×nb×nc 超胞堆垛，层间距 d001 只作用于层间平移)
        → [六角掩膜裁剪]（高岭土天然"假六方"片貌，对齐 M1 样图）
        → addHydroxylHydrogens(1989 CIF 无 H 位点 → 沿 Al→O 方向补羟基氢)
        → computeBonds(共价半径判据 + 空间哈希，O(N))
        → [saturateEdges(边缘羟基饱和)]
        → { atoms, bonds } 交给渲染层
```

**切片（尺寸控制）**：目标尺寸 `Lx×Ly` → `na = round(Lx/a)`、`nb = round(Ly/b)` 个晶胞 → 在**分数坐标空间**裁剪（保证边缘沿晶面、整齐不锯齿）。片层厚度自动 = 单层实际厚度（≈5.1 Å 原子包络 / 7.4 Å 晶胞重复）。

```ts
// —— 切片生成的核心（demo/core/crystal.js · buildSlab 摘要）——
function buildSlab(parsed, opts: {na, nb, nc, d001}) {
  const base = expandSymmetry(parsed.atoms, parsed.symops);   // 对称展开
  const atoms = [];
  for (let k = 0; k < opts.nc; k++)                            // 层
    for (let j = 0; j < opts.nb; j++)                          // b 方向
      for (let i = 0; i < opts.na; i++)                        // a 方向
        for (const a of base) {
          const zIntra = a.fz * parsed.cell.c;                 // 层内厚度不缩放！
          const p = fracToCart(L, a.fx + i, a.fy + j, 0);
          atoms.push({ el: a.el, x: p.x, y: p.y, z: zIntra + k * opts.d001 });
        }
  return center(atoms);   // 包围盒居中
}
```

> **层间距的细节**：`d001` 只加在"层与层"的平移上，**不缩放层内坐标**——否则调层间距会把 TO 单层本身拉厚。d001=7.4 Å 是脱水高岭石；调到 10 Å 即呈现水合间层（视觉对应 10Å 埃洛石管壁间距）。

### 5.2 卷曲算法（片层 → 埃洛石管）

**数学：保弧长等距（isometric）映射。** 设片层沿卷曲方向长 `Lx`，卷曲角 `φ = progress × 2π`，中面半径 `Rmid = Lx / φ`（progress=1 时恰好闭合成圆管）。片层中任一原子：`u` 为沿卷曲方向坐标，`δz` 为相对片层中面的高度。

```
锥形(可选)   Rm(u) = Rmid + (u − Lx/2)·tanα
卷曲角       θ(u) = φ · F(u)/F(Lx)，  F(u) = ∫₀ᵘ du′/Rm(u′)   （α→0 退化为 θ = φ·u/Lx）
径向映射     r = Rm(u) − δz          （+δz 面 → 管内壁）
坐标         X = r·sinθ,  Y = y,  Z = Rmid − r·cosθ
```

四个物理/视觉性质，全部自动成立：

1. **卷曲方向即化学方向**：本 CIF 中 +z 侧是铝羟基（Al-OH）面 → 卷后半径小 → **Al-OH 为内壁、Si-O 为外壁**，与真实埃洛石一致（Demo 截图管口可见白色羟基内圈）。
2. **弧长按各自半径保持** → 内壁受压、外壁受拉，符合真实弯曲应变分布，原子不会"挤成一团"。
3. **progress 是连续参数**：0% = 平片，100% = 闭合管，拖滑块即得"片层卷成管"机理动画（演示截图见 §9）。
4. **开口端自动断键**：卷曲后**重新判定键连**，φ<2π 时两端距离拉开、超判据的键自然断开——不需要任何手工断键逻辑。

```ts
// —— 卷曲变换（demo/core/builders.js · rollToTube 摘要）——
function rollToTube(atoms, p: {progress, taperDeg}) {
  const phi  = clamp(p.progress, 0.001, 1) * 2 * Math.PI;
  const Lx   = maxX - minX,  half = Lx / 2;
  const zMid = (minZ + maxZ) / 2;
  const Rmid = Lx / phi;                                   // 中面半径
  const t    = Math.tan(p.taperDeg * Math.PI / 180);       // 锥角（0 = 圆柱）
  const F    = (u) => Math.abs(t) < 1e-6 ? u / Rmid        // F(u)=∫du/Rm
             : Math.log((Rmid + (u - half) * t) / (Rmid - half * t)) / t;
  const Ftot = F(Lx) - F(0);

  return atoms.map(a => {
    const u  = a.x - minX;
    const th = phi * (F(u) - F(0)) / Ftot;                 // 卷曲角
    const Rm = Rmid + (u - half) * t;                      // 局部半径（圆锥）
    const r  = Rm - (a.z - zMid);                          // 径向映射
    return { el: a.el, x: r * Math.sin(th), y: a.y, z: Rmid - r * Math.cos(th) };
  });
}
```

**埃洛石管 Builder**（`buildHalloysiteTube`）：用户给 `innerR（内半径）` → 周向晶胞数 `na = round(2π(innerR+3.6)/a)`；`length` → `nb = round(length/b)`；`walls = 2~3` 时先堆垛多层片层再整体卷曲，自动得到同心多层壁（层间距用 d001 参数，10 Å 即水合多层埃洛石）；`taperDeg` 锥角生成天然锥形管。

**半径怎么定（视觉模式 vs 物理模式）**：作图时用户直接拖 `innerR` 即可（视觉模式，默认）。物理模式作为辅助初值：用弹性板弯曲估算——中性面弯曲应变 ≈ t/(2R)，令其等于 T 片与 O 片的晶格失配度 δ（高岭土约 2–5%）得 `R₀ ≈ t/(2δ)`；t≈7.2 Å、δ=3% 时 R₀≈12 nm，与文献埃洛石常见外径 40–70 nm / 内径 10–20 nm 同量级。最终以视觉/微调为准，软件内注明这是估算。

> 文献中真实埃洛石管轴多为 [110] 向、常带锥度与端口不规则；软件以"卷曲方向选项（a/b 轴向）+ 锥角 + 端口噪声（路线图）"覆盖，作图场景下轴向选择以构图美观优先。

### 5.5 渲染工程与性能

- **InstancedMesh 按元素分桶**：每种元素一个实例网格，一次 draw call 渲染上万原子（Demo 预设场景 16,097 原子实时 60fps）。
- **LOD**：原子数 >6k 用 12 段球、>15k 用 8 段球。
- **重建节流**：滑块拖动合并到 rAF 帧，参数变化即全量重建（2–5k 原子 <10 ms，无感）。
- **批量预烘焙**：几何内核可在 Worker/Node 中预生成常用尺寸的网格缓存，模块拖入零等待（第二阶段）。
- 实测数据：双层壁埃洛石管（innerR 14 Å、长 100 Å、壁距 10 Å）= 15,686 原子、生成 < 200 ms。

| **渲染档**（宣讲/会议） | MeshPhysicalMaterial（roughness≈0.42 + clearcoat 0.4）+ PMREM 室内环境光 + 主光/补光；浅灰背景；逐原子 5% 明度抖动增加"手作"质感 | PPT、会议墙报 |
| **线稿档**（出版/投稿） | 扁平色块 + 均匀描边（MeshToonMaterial/gradientMap 或 SVG 路径），无高光无阴影 | 期刊示意图、与箭头/标注混合 |

- **色板**：低饱和学术色（Demo 内置：O `#D64550`、Si `#E2C47E`、Al `#C9A2A2`、Ce `#C77E8E`、H `#ECECEC`…），提供 3–4 套预设色板 + 逐元素取色器（路线图）。配色直接可复用样例图中的"红 O / 米黄 Si / 银灰金属"体系。
- **构图预设**：等距视角一键、水平线吸附、比例尺/晶胞参数标注层（路线图）。
- 所有颜色在 sRGB 输出编码下做线性化转换（`convertSRGBToLinear`），保证"所见即所得"（Demo 调试时踩过的坑，已固化在代码里）。

## 7. 导出引擎实现要点

```ts
// 位图导出：16cm 版面宽 × dpi → 像素（Demo 已实现 exportPNG）
const w = Math.round(16 /*cm*/ * dpi / 2.54);        // 300dpi → 1890px；600dpi → 3780px
const h = Math.round(w * canvasH / canvasW);
renderer.setPixelRatio(1); renderer.setSize(w, h, false);
camera.aspect = w / h; camera.updateProjectionMatrix();
if (alpha) scene.background = null;                  // 透明底（PPT 叠放友好）
renderer.render(scene, camera);
const url = canvas.toDataURL('image/png');           // 同步快照后再恢复画布尺寸
```

| 格式 | 实现 | 备注 |
|---|---|---|
| PNG | 如上，支持透明底 | 期刊线稿/位图皆宜 |
| JPG | `toBlob('image/jpeg', 0.95)` | 汇报快速插图 |
| **TIFF** | 画布 → `getImageData` → **UTIF.encodeImage**（纯前端） | 期刊 300dpi+ 硬要求；桌面端可用 Rust `image` crate |
| PDF | jsPDF：位图按物理尺寸嵌入；或 svg2pdf.js 矢量嵌入 | 投稿系统通用 |
| **SVG（分组）** | `THREE.SVGRenderer`，每组件包 `<g id="组件名">`；矢量模式自动切**线稿档**材质（逼真光照无法矢量化的诚实取舍） | → PPT 转形状 / Inkscape → EMF/PDF |
| 分层 PNG | 遍历图层：只显示当前层 → 逐层透明 PNG | PPT 保留质感 + 可单独编辑 |

## 10. 风险与备选

| 风险 | 应对 |
|---|---|
| 逼真渲染 vs PPT 可编辑矢量的矛盾 | 已定为双轨渲染 + 三条 PPT 路径（§4.3/§6），用户按场合选 |
| 化学正确性争议（示意 vs 模拟） | 软件定位**机理示意图**：示意正交化、羟基氢近似放置均在 UI 注明；审稿级结构图可切换"晶学严格模式"（保留 β/γ 夹角，路线图开关） |
| 大场景性能 | InstancedMesh + LOD + Worker 预烘焙 + 网格缓存；上限预估 10⁵ 原子 |
| 浏览器存储上限 | 模块库迁移 IndexedDB / 工程文件夹（桌面端），JSON 极小无压力 |
| **Mol\*/3Dmol.js 为什么不直接用** | 它们是"结构查看器"（给 PDB/CIF 看真实结构），缺三样核心能力：①参数化变形（尺寸/层数/卷曲度/锥度）；②非破坏模块库；③期刊风格版式导出。但其 CIF 解析器（MIT）值得借鉴/直接复用到生产版 |
| 真实埃洛石形貌细节（端口不规则、[110] 轴向） | 路线图：端口噪声修饰、卷曲方向选项；作图以美观为先 |
