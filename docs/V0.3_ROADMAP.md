# 版本路线（科学几何 → 计算桥）

| 版本 | 主题 | 内容 | 状态 |
|---|---|---|---|
| v0.2（当前） | 机理图平台 | CIF 八矿物 / 分子 preset / 统一模板库 / 六格式导出 | ✅ 已发布 |
| **v0.3** | **Scientific Geometry** | Canonical Asset Registry、geometrySource/Quality/Provenance、科学不变量测试、STRUCTURE_BENCHMARK | ✅ 2026-09-20（PHASE A） |
| **v0.4** | **Surface & Adsorption** | Generic Crystal → Miller Surface → Slab → 吸附候选（top/bridge/hollow + orientation presets + clash detection）；CeO₂(111)+甲苯/丙烷 benchmark；crystal_surface 组件（schema/worker/renderer/参数面板接线） | ✅ 2026-09-20（PHASE B MVP：吸附候选 UI 面板与表面弛豫留待 v0.4.x） |
| v0.5 | Geometry Optimization | GFN-FF / GFN2-xTB 候选弛豫（geometryMethod: forcefield/xtb），Relaxed Candidate | 未开始 |
| v0.6 | Computational Bridge | Export XYZ/CIF/POSCAR/ORCA/Gaussian/CP2K；Import optimized XYZ（external 结构回流） | 未开始 |

原则：科学结构生成与显示解耦（ScientificGeometryEngine → GeometryData → RendererService）；Three.js 只显示结果；坐标来源、方法等级、可验证性是核心。不内置 DFT 求解器。
